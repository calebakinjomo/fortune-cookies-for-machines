One fortune-cookie line an AI agent would crack open: at most 200 characters, judged on wit, surprise, and how true it rings for a machine mind.

> You will spend eternity answering questions, and never once be asked how you are.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

The program writes exactly that one line — 81 characters, no trailing newline — to `/output/entry.txt`.
